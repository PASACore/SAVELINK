# SAVELINK📥
## PURPOSE
### English
SAVELINK is a simple, open-source application for downloading YouTube videos in the highest available resolution, without worrying about viruses.
### Turkish
SAVELINK, YouTube videolarını virüs endişesi olmadan, mevcut en yüksek çözünürlükte indirmeyi sağlayan basit, açık kaynaklı bir uygulamadır.
